# CS404 – Artificial Intelligence (Sabancı University) | Homework Repository 🧠🤖

This repository contains my completed homework assignments for **CS404 (Artificial Intelligence)** at **Sabancı University**. The homeworks cover core AI foundations—from **local search and optimization**, to **logical reasoning**, to **rule-based inference with Prolog**.

---

## 📌 Homeworks Included

### ♟️ HW – Local Search (N-Queens)
Implemented and tested **local search algorithms** on the **N-Queens problem** (including larger settings such as **N=20**) to evaluate success behavior across repeated runs.
**Includes:**
- Hill Climbing  
- Hill Climbing with Random Restarts  
- Stochastic Hill Climbing  
- Experimental evaluation over multiple trials (e.g., repeated runs), analyzing success and runtime behavior

---

### 🧾 HW – Knowledge Representation & Reasoning (Logic)
Focused on **formal reasoning** and **knowledge representation**, using both propositional and first-order logic.
**Includes:**
- Propositional reasoning (Tiny Wumpus World style questions)
- Entailment checks via truth tables
- Step-by-step **CNF conversion**
- Writing **First-Order Logic (FOL)** representations of English statements

---

### 🧬🇹🇷 HW – Prolog Self-Learning (Family Relations)
Extended a Prolog knowledge base and implemented relationship reasoning using **SWI-Prolog / SWISH**.
**Includes:**
- Extending a given family knowledge base
- Implementing Turkish relationship predicates (e.g., *hala, teyze, dayı, amca, anneanne, babaanne, gelin, damat, torun, dünür*)
- Writing predicates that list **married couples only once** (avoiding duplicates)
- Conceptual Prolog questions: execution order, rule behavior, and debugging/trace-style reasoning
